# VEO Branded PDF

Every PDF generated by VEO must look like the cotización (`COT0167/26`) and contrato (`CON0633/26`). Both are built from one shared design system. **Reuse it, never re-create it.**

## Source of truth (read before writing)

| File | What it gives you |
|------|-------------------|
| `apps/web/src/components/pages/my-space/document/veo-document-styles.ts` | `px()`, `DOC_COLORS`, `DOC_LOGO`, `display`, `eyebrow`, `docStyles` |
| `apps/web/src/components/pages/my-space/document/veo-document-parts.tsx` | `DocHeader`, `DocTitle`, `DocInfoCell`, `DocSignatures`, `DocFooter`, `LESSOR_COMPANY_NAME` |
| `apps/web/src/lib/pdf-document-fonts.ts` | `registerDocumentFonts()` (Funnel Sans 300/400/600 + Funnel Display 600) |
| `apps/web/src/lib/pdf-download.ts` | `downloadBlob`, `safeFileName`, `blobToBase64` |
| `apps/web/src/components/pages/my-space/quotation/offer-pdf-*.ts(x)` | Reference: items tables, totals block, payment box |
| `apps/web/src/components/pages/my-space/contract/contract-pdf-*.ts(x)` | Reference: summary grid with highlight cell, detail table, two-column clauses |

Do **not** use `@/components/pdfx/*` or `@/lib/pdfx-theme` for new documents; that is the older, off-brand style.

## File layout for a new document

Follow the offer/contract split, in the feature's folder:

```
<feature>/
├── <name>-pdf-document.tsx   # <Document>/<Page> composition only
├── <name>-pdf-parts.tsx      # document-specific sections (tables, grids)
├── <name>-pdf-styles.ts      # StyleSheet built from px/DOC_COLORS/display/eyebrow
├── <name>-pdf-copy.ts        # fixed Spanish copy + formatters (optional)
└── download-<name>-pdf.tsx   # pdf(...).toBlob() + downloadBlob
```

## Page anatomy (mandatory order)

**First page**
1. `<DocHeader meta={formatHumanDayDate(date)} />` — logo left; `ARHEDES S.A. DE C.V.` + date right; 2px ink rule below.
2. `<DocTitle title="TÍTULO" badge={documentNumber} />` — big Funnel Display title (use `\n` for two lines) + ink badge with a lime square.
3. Intro paragraph (Light 300, `px(11)`, `lineHeight: 1.65`), optional gray display tagline.
4. Info grid(s) built with `DocInfoCell` inside `docStyles.infoGrid` / `infoRow`.
5. Tables / content sections.
6. `<View style={d.spacer} />` then `<DocSignatures>` when the document needs signing.
7. `<DocFooter dotColor={DOC_COLORS.ink} />`.

**Following pages**
1. `<DocHeader meta={documentNumber} />` (or no meta).
2. `<Text style={d.pageTitle}>SECCIÓN</Text>` (e.g. `CONDICIONES`, `CLÁUSULAS`).
3. Content.
4. Last page footer uses `dotColor={DOC_COLORS.lime}`; it may carry `note={LESSOR_ADDRESS}`.

Always `<Page size="LETTER" style={d.page}>`. The page padding already reserves room for the fixed footer — do not override it.

## Skeleton

```tsx
"use client";

import { Document, Page, Text, View } from "@react-pdf/renderer";
import { formatHumanDayDate } from "@/lib/format";
import { registerDocumentFonts } from "@/lib/pdf-document-fonts";
import {
  DocFooter,
  DocHeader,
  DocInfoCell,
  DocSignatures,
  DocTitle,
} from "@/components/pages/my-space/document/veo-document-parts";
import {
  DOC_COLORS,
  docStyles as d,
} from "@/components/pages/my-space/document/veo-document-styles";
import { exampleStyles as s } from "./example-pdf-styles";

registerDocumentFonts();

export function ExamplePdfDocument({ data }: { data: ExamplePdfData }) {
  return (
    <Document title={`Documento ${data.number}`} author="VEO Media" creator="VEO Media">
      <Page size="LETTER" style={d.page}>
        <DocHeader meta={formatHumanDayDate(data.date)} />
        <DocTitle title="DOCUMENTO" badge={data.number} />
        <Text style={s.intro}>{data.intro}</Text>

        <View style={d.infoGrid} wrap={false}>
          <View style={d.infoRow}>
            <DocInfoCell label="CLIENTE:" value={data.client} valueStyle={s.infoValue} />
            <DocInfoCell label="TOTAL:" value={data.total} valueStyle={s.infoValue} highlight />
          </View>
        </View>

        <View style={d.spacer} />
        <DocSignatures
          signers={[
            { label: "Por: ARHEDES S.A. DE C.V.", name: data.lessorSigner },
            { label: "Por:", name: data.client },
          ]}
        />
        <DocFooter dotColor={DOC_COLORS.lime} />
      </Page>
    </Document>
  );
}
```

Download helper:

```tsx
import { pdf } from "@react-pdf/renderer";
import { downloadBlob, safeFileName } from "@/lib/pdf-download";

export async function downloadExamplePdf(data: ExamplePdfData) {
  const blob = await pdf(<ExamplePdfDocument data={data} />).toBlob();
  downloadBlob(blob, safeFileName(`Documento ${data.number}.pdf`));
}
```

## Brand rules

- **Colors**: only `DOC_COLORS`. Ink `#1B2629` for text, rules, badges and strong rows. Lime `#BAEB56` is an accent only: small squares, highlight labels on ink, the "TOTAL A PAGAR" row, the last-page footer dot. Ice `#E8F6F9` for table header rows and callout boxes. Gray `#4A798C` for eyebrows, labels and taglines. Never introduce new hex values.
- **Squares, not circles**: every dot/bullet is a square `View` (no `borderRadius`). No rounded corners anywhere.
- **Typography**: titles, codes, figures and values use `display` (Funnel Display 600). Large body copy is Funnel Sans Light 300; small print (< ~`px(10)`) uses Regular 400. Labels use `eyebrow` (uppercase, tracked, gray, ending with `:`).
- **Sizes**: write all sizes in design px and wrap with `px()` (96 dpi → points). Use the existing scale: 36 titles, 20/16/14 values, 11 body, 10 tables, 8.5 labels.
- **Logo**: only through `DocHeader` (`/veo-logo-dark.png`, `DOC_LOGO` dimensions). Do not stretch, recolor or swap it.
- **Copy**: Spanish, uppercase headings/labels. Dates via `@/lib/format` (`formatHumanDayDate`, `formatHumanDateRange`, `formatLongDate`). Money as `$ 1,151.00` (see `formatCurrency` in `offer-pdf-copy.ts`). Empty values render `—`.

## Tables

Reuse `d.tableHeadRow` (ice background, 2px ink bottom rule), `d.th`/`d.thText`, `d.tableRow`, `d.td` (subtle bottom border), `d.tdCode` for the first code column and `d.tdArea` for gray secondary text. Define columns as `{ heading, width: "NN%", align? }` arrays whose widths sum to 100%. Section titles are an ink square + display text (`offerStyles.sectionTitle*`). Totals follow `TotalsBlock`: ice header, subtle rows, ink grand row with lime label, lime payable row.

## react-pdf gotchas

- Call `registerDocumentFonts()` at module top level of the document file.
- Put `wrap={false}` on table rows, info grids, totals and signatures; give section titles `minPresenceAhead` so they don't orphan.
- Never set `lineHeight` on a `Text` that uses `render` (page numbers) — react-pdf drops it.
- No CSS columns or grid: use flex rows with percentage widths (see `splitClauses` for balanced two-column text).
- Hyphenation is disabled globally; keep long codes short or give them width.
- Files that render on demand must be client code (`"use client"` or imported only from client components).
