# Website — UI kit

Recreated from the only web reference in the brand manual: the two laptop screens on p.98 (hero "Tú dinos quién. Nosotros, dónde." and contact "Haz tu marca visible, verificable, ahora."). The mockup is small, so nav labels, the location line and the 24h caption are reconstructed approximations — confirm against the real site.

- `Site.jsx` — `SiteNav`, `Home` (BAR photo, lime billboard panel, lime ↗ tile CTA), `Contact` (Lime/Ice split, underline form, Dark sign-off band)
- `index.html` — click "Hazlo ahora" or "Contacto" to switch screens.
