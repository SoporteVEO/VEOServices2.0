Interface glyph for buttons, nav and status — Lucide path data drawn with square caps and miter joins to echo VEO's pixel-cut forms.

```jsx
<Glyph name="arrow-up-right" size={16} />
<Glyph name="shield-check" size={20} color="var(--veo-gray)" />
```

- For OOH inventory (billboards, screens, mupis…) use OOHIcon instead — those are the brand's own icons.
